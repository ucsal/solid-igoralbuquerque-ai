# Refatoração SOLID – Sistema das Olimpíadas

## Objetivo
Aplicar os princípios SOLID em um sistema legado sem alterar seu comportamento original.

## Princípios aplicados

SRP: Separação de responsabilidades com ParticipanteService  
OCP: Uso de interface CalculadoraNota  
LSP: Implementações substituíveis  
ISP: Interface simples  
DIP: Dependência de abstração  

## Conclusão
Código mais organizado e fácil de manter.
